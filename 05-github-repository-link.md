\# Assignment 5 – GitHub Repository Link



\## Push Steps



1\. Create a new repository on GitHub named `HTML-CSS-Assignments`.

2\. In your local project folder, connect your GitHub repository using the following commands:



```bash

git remote add origin https://github.com/impriyanshiiee-eng/HTML-CSS-Assignments.git

git branch -M main

git push -u origin main

```



3\. Refresh the GitHub repository page and confirm that all files and commits appear.



\*\*Note:\*\* The repository has already been created and pushed successfully.



\## Optional: Host It for Free



To host the project using GitHub Pages:



1\. Open your GitHub repository.

2\. Go to \*\*Settings → Pages\*\*.

3\. Under \*\*Build and deployment\*\*, select:

&#x20;  - Source: Deploy from a branch

&#x20;  - Branch: `main`

&#x20;  - Folder: `/ (root)`

4\. Click \*\*Save\*\*.



Your website URL will be:



https://impriyanshiiee-eng.github.io/HTML-CSS-Assignments/
